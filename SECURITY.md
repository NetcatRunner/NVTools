# Security Policy

## Supported versions

Security patches are provided exclusively for:
- **Pre-1.0:** The `main` branch only.
- **1.0 and later:** The latest release only.

## Report a vulnerability

**Do not report security vulnerabilities in public GitHub issues.**

Report them privately through GitHub:
1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.

Please include the following details in your report:
- **Version:** The affected release tag or commit hash.
- **Reproduction:** The exact input, payload, or steps that trigger the issue.
- **Impact:** The observed behavior and its security effect.
